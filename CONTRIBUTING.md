# Contributing

Codex1 is a public starter kit for cleaner AI-assisted software engineering workflows.

## Contribution Standard

Contributions should improve at least one of these:

- task clarity
- agent reliability
- reviewability
- safe handoffs
- public-safe templates
- reusable software-factory habits

## Public Safety

Do not contribute private, sensitive, employer-specific, customer-specific, or production-specific material.

Use fake data, sample data, and generic examples only.

## Preferred Change Types

- small protocol improvements
- new templates
- filled-in examples using fake data
- documentation clarifications
- issue or PR workflow improvements
- simple tooling after the manual workflow is proven

## Before Opening a PR

- [ ] Read `README.md`.
- [ ] Read `AGENTS.md`.
- [ ] Check `docs/public-readiness-checklist.md`.
- [ ] Keep the change focused.
- [ ] Avoid unrelated refactors.

## Review Standard

A good PR is understandable, safe, and useful without requiring private background context.
