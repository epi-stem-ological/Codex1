# Public Readiness Checklist

Use this checklist before moving any workflow, template, prompt, example, or protocol into this public repository.

## Purpose

Codex1 is public by design. Every artifact should be safe for strangers, recruiters, collaborators, and future clients to read.

## Checklist

- [ ] Contains no secrets, tokens, passwords, API keys, or credentials.
- [ ] Contains no real personal financial records, tax records, bank data, or debt details.
- [ ] Contains no private family information.
- [ ] Contains no real contact lists, phone numbers, emails, addresses, or personal CRM notes.
- [ ] Contains no employer-confidential information.
- [ ] Contains no customer, vendor, or production infrastructure details.
- [ ] Contains no screenshots with private context.
- [ ] Uses fake data, sample data, or generic examples only.
- [ ] Clearly labels opinion, inference, and evidence when relevant.
- [ ] Can be understood without private background context.
- [ ] Improves the public toolkit instead of acting as a personal note dump.

## Publish Decision

If any item above is not satisfied, keep the artifact private or sanitize it further before publishing.
