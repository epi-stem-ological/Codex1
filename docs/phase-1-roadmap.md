# Phase 1 Roadmap

## Goal

Turn Codex1 into a clean public starter kit for AI-assisted software engineering workflows.

## Phase 1 Outcomes

By the end of Phase 1, the repo should help a user do four things:

1. Define a clear coding-agent task.
2. Give the task to Codex, Claude Code, ChatGPT, or another agent.
3. Receive reviewable output.
4. Hand the work off safely to a human or another agent.
